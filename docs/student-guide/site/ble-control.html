MANGOLITE · BLE CONTROL V1

BLE Control v1 快速入門

MangoLite Runtime v0.6.3 在 Pico W 與 Pico 2 W 上提供 BLE Control v1，可直接使用 Dabble 的 Gamepad 模組控制 MangoBox。BLE Control 與既有 UART Runtime 共存，學生仍以 MangoBox Student API 綁定按鍵與搖桿事件。

支援 target：MangoLite + Pico W、MangoLite + Pico 2 W。一般開機不主動 BLE advertising；需要配對時，長按板載 GP3 約 10 秒開啟配對視窗。

1. 使用 Dabble 配對

  1. 啟動 MangoLite v0.6.3。
  2. 長按板載按鈕 GP3 約 10 秒。
  3. 聽到提示音後，在手機 Dabble App 連線到裝置名稱，例如 ML-B032。
  4. 進入 Gamepad 模組。

配對視窗期間按一下板載按鈕可取消配對。斷線時 Runtime 會清理控制狀態，避免 RGB、Motor 等輸出因失去控制端而保持在按住狀態。

2. Digital Gamepad

方向鍵、Triangle、Circle、Cross、Square、Start、Select 等按鍵會產生 press / release 事件。未綁定的按鍵只保留控制事件，不會自動操作硬體。

from mangobox import Mango

m = Mango()

def up_pressed():
    print("UP pressed")

m.on_control_pressed("up", up_pressed)
m.run_forever()

3. Analog Joystick

Dabble Analog Joystick 提供 angle 與 radius。angle 可視為 0–359° 的方向角，radius 代表搖桿離中心的程度，可用來控制車速、轉向或燈光色相。

from mangobox import Mango

m = Mango()

def joystick(angle, radius):
    print("angle=", angle, "radius=", radius)

m.on_control_joystick(joystick)
m.run_forever()

4. 色相環燈光

可把 joystick angle 對應 HSV 色相，radius 對應亮度，形成類似色相環的互動控制。官方範例原始碼位於 Runtime examples 中的 ble_joystick_hue_ring.py。

5. 車控範例

v0.6.3 提供兩種車控範例：

  • Digital Car：方向鍵控制前進、後退、pivot 左右；Triangle / Cross 調整速度，Circle 蜂鳴器，Square 切換板載 RGB。
  • Analog Car：使用 joystick angle / radius 做連續速度與轉向控制。

車子的左右輪方向不要在 BLE 層補正。請先使用 Device Manager 的 Motor Direction Calibration 校正車體，讓 forward() 永遠代表車體真正向前。

6. 多裝置 Student API

BLE Control 不改變 MangoBox 原有的 named-device 設計。若有多組 LED strip、IR 或其他模組，仍使用既有 Student API 的裝置名稱或 selector 指定目標；控制器事件只負責觸發 callback。

版本需求

  • MangoLite Runtime：v0.6.3 或更新。
  • 控制板：Raspberry Pi Pico W 或 Pico 2 W。
  • App：Dabble，使用 Gamepad 模組。
