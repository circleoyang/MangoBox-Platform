# MangoX2 Runtime

正式版 / Stable: v0.2.7

- [MangoX2 + Pico](https://github.com/circleoyang/MangoBox-Platform/releases/tag/mangox2-pico-v0.2.7)
- [MangoX2 + Pico W](https://github.com/circleoyang/MangoBox-Platform/releases/tag/mangox2-picow-v0.2.7)

v0.2.7 加入 High-Level MicroPython 感測器 polling Learning Log parity，讓 Light、Sound、Joystick、PIR 與 IR 等讀取事件可進入既有 MangoBox Learning Log；Student API 回傳值、GPIO、執行模式與既有硬體控制語意維持不變。

每個 target 各自發布 UF2、SHA-256 與雙語說明。請依主板與控制板組合選擇檔案。

Each target has its own UF2, SHA-256 and bilingual release notes. v0.2.7 adds High-Level MicroPython polling Learning Log parity while preserving existing Student API return values, GPIO configuration, execution modes, and hardware-control semantics. Engineering source remains in the private repository; binaries are distributed through GitHub Releases.
