# MangoLite Runtime

正式版 / Stable: v0.6.2

- [MangoLite + Pico W](https://github.com/circleoyang/MangoBox-Platform/releases/tag/mangolite-picow-v0.6.2)
- [MangoLite + Pico 2 W](https://github.com/circleoyang/MangoBox-Platform/releases/tag/mangolite-pico2w-v0.6.2)

v0.6.2 加入 High-Level MicroPython 感測器 polling Learning Log parity，讓 Light、Sound、Joystick、PIR 與 IR 等讀取事件可進入既有 MangoBox Learning Log；Student API 回傳值、GPIO、執行模式與既有硬體控制語意維持不變。此版本延續 v0.6.1 的 Ultrasonic parity 與 Device Manager v0.5.1 對齊基線。

每個 target 各自發布 UF2、SHA-256 與雙語說明。請依控制板選擇檔案。

Each target has its own UF2, SHA-256 and bilingual release notes. v0.6.2 adds High-Level MicroPython polling Learning Log parity while preserving existing Student API return values, GPIO configuration, execution modes, and hardware-control semantics. It keeps the Ultrasonic parity baseline introduced in v0.6.1. Engineering source remains in the private repository; binaries are distributed through GitHub Releases.
