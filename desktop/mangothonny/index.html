MangoThonny

v0.4.3 StableWindowsPortable + InstallerPersistent AssignmentLearning Log

MangoThonny 是 MangoBox 的教學用 Python 與實體運算 IDE，以 Thonny Portable 為基礎，整合 MangoBox Host Student API、Mango App Exporter、教學套件、範例與學習歷程工具。v0.4.3 將 Learning Log 延伸成可持續的 Assignment Workspace：同一份作業可以跨多次執行、跨日期、跨 MangoThonny 啟閉，並可透過「帶走作業／匯入作業」在不同電腦間延續，同時保留程式快照、執行輸出、錯誤、硬體事件與同一個 assignment_id。

v0.4.3 Installer 發布檔待上架v0.4.3 Portable 發布檔待上架安裝與使用說明v0.4.3 Release Notes
版本狀態：v0.4.3 已完成 Portable／Installer 建置、安裝與解除安裝 smoke、Host Python／High-Level MicroPython Learning Lifecycle、跨電腦作業續作，以及 Light／Ultrasonic 高頻感測摘要實機驗證。GitHub Release 二進位檔尚未上架前，請勿使用不存在的下載連結；v0.4.2 仍可由下載中心取得。

Persistent Assignment

  • 以 student_id、task_id 與持久化 assignment_id 管理同一份作業。
  • 每次 Run 保留 code snapshot、輸出、錯誤與 terminal status。
  • 「帶走作業」可將程式與歷程一起封裝；「匯入作業」可在另一台電腦延續。
  • 跨電腦時保留原 assignment identity，並以匿名 computer identity 區分不同工作站。

Learning Log

  • Host Python 與 High-Level MicroPython 共用 Event Schema 1.1。
  • High-Level MicroPython Student API events 與 frontend lifecycle 共用同一 run_id。
  • High-Level 原始 @@MANGO_EVENT@@ 預設隱藏，但資料仍持續收集。
  • 一般本機 Learning Log 仍支援本次執行、本次工作階段、今天與自訂時間區間匯出。

高頻感測資料

  • 連續感測 polling 採 bounded queue 與 constant-memory aggregation。
  • Light、Sound、Joystick、PIR、IR、Ultrasonic、Obstacle 等連續讀取可彙整為 hardware_summary。
  • 真正的按下／放開／門檻跨越等語意事件仍保留單筆 evidence。
  • Host frontend 與 child runtime 可跨 process 完成 run-end summary reconciliation。

教學整合

  • HostPython 教學範例 01–20 與多媒體 / AI assets。
  • Standard Teaching Packages v1。
  • canonical mangobox import 與 legacy mangox2 相容。
  • Mango App Exporter 可將桌面 Python 專案打包為 Windows 執行程式。

支援硬體

  • MangoX2 + Pico
  • MangoX2 + Pico W
  • MangoX2 + Pico 2 W
  • MangoLite + Pico W
  • MangoLite + Pico 2 W
