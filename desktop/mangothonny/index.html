MangoThonny

v0.4.2 StableWindowsPortable + InstallerLearning Log

MangoThonny 是 MangoBox 的教學用 Python 與實體運算 IDE。它以 Thonny Portable 為基礎，整合 MangoBox Host Student API、Mango App Exporter、教學套件、範例與 MangoBox 品牌介面。v0.4.2 新增 MangoBox Learning Log 工作流程，讓 Host Python 與 High-Level MicroPython 共用同一套學習歷程收集與匯出機制，同時預設隱藏 High-Level MicroPython 的原始事件訊息，保留學生真正需要看到的程式輸出與感測值。

下載 Windows Installer下載 Portable安裝與使用說明Release Notes

教學整合

  • HostPython 教學範例 01–20 與多媒體 / AI assets。
  • Standard Teaching Packages v1。
  • canonical mangobox import 與 legacy mangox2 相容。
  • Mango App Exporter 可將桌面 Python 專案打包為 Windows 執行程式。

Learning Log

  • Host Python 與 High-Level MicroPython 共用 per-user JSONL 紀錄。
  • High-Level MicroPython 原始 @@MANGO_EVENT@@ 預設隱藏，但資料仍持續收集。
  • 支援本次執行、本次工作階段、今天與自訂時間區間匯出。
  • 匯出 ZIP 內含 events.jsonl、manifest.json、summary.csv。
