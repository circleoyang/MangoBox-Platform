MangoThonny

v0.4.0 StableWindowsPortable + Installer

MangoThonny 是 MangoBox 的教學用 Python 與實體運算 IDE。它以 Thonny Portable 為基礎，整合 MangoBox Host Student API、Mango App Exporter、教學套件、範例與 MangoBox 品牌介面，讓學生可以在同一環境中進行桌面 Python、MicroPython 與 Pico 實機操作。

下載 Windows Installer下載 Portable安裝與使用說明Release Notes

教學整合

  • HostPython 教學範例 01–20 與多媒體 / AI assets。
  • Standard Teaching Packages v1。
  • canonical mangobox import 與 legacy mangox2 相容。
  • Mango App Exporter 可將桌面 Python 專案打包為 Windows 執行程式。

硬體目標

  • MangoX2 + Pico
  • MangoX2 + Pico W
  • MangoX2 + Pico 2 W
  • MangoLite + Pico W
  • MangoLite + Pico 2 W

安裝版資料隔離

設定、學習 workspace 與 cache 會放在 LocalAppData 的 MangoBox/MangoThonny 目錄，不污染程式安裝目錄；解除安裝時可選擇保留學習資料。
