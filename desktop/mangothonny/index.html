MangoThonny

v0.4.3.1 StableWindowsPortable + InstallerAssignment ModeLearning Log中文 Error Advisor

MangoThonny 是 MangoBox 的教學用 Python 與實體運算 IDE，以 Thonny Portable 為基礎。v0.4.3.1 以「作業模式與學習支援」為核心：學生可在同一個 Assignment Project 中撰寫、執行、除錯、跨電腦續作與正式繳交；系統同步保留 Learning Log，並在右側 Assistant 提供依目前程式碼產生的繁體中文除錯提示。

下載 Windows Installer下載 Portable安裝與使用說明中／英文 Release Notes
版本狀態：v0.4.3.1 的 Portable、Installer、Assignment Mode、Error Advisor、Learning Log analytics 與正式 Windows install／launch／shortcut／upgrade／uninstall／reinstall smoke 均已完成驗證並發布。

Assignment Mode

  • 主工具列直接顯示作業狀態、歷程、存檔、專案與容量資訊。
  • 開始作業時自動建立作業資料夾與 main.py，作業代碼自動轉大寫。
  • 作業開始或匯入後鎖定學號與作業代碼，避免中途誤改。
  • Assignment Mode 啟用時將檔案瀏覽器限制在目前 Project Root，並防止作業外檔案干擾歷程。
  • 支援「帶走作業／匯入作業／完成並匯出作業」的跨電腦續作流程。

繁體中文 Error Advisor

  • 支援常見 Syntax、Indentation、Name、Type、Index、Value、Import、File、Attribute 與 OSError／I/O 等錯誤。
  • 採離線規則與 Python AST／靜態分析，不需網路服務。
  • 可利用目前錯誤行與前面簡單變數指定，提供 source-aware 提示。
  • 以「找問題 → 怎麼修改 → 怎麼確認」引導學生除錯。
  • Shell 保留原始 Python traceback，右側 Assistant 聚焦 MangoBox 教學提示。

Learning Log 與 Advisor Analytics

  • 記錄程式執行、錯誤、程式快照、輸出、硬體 evidence 與 Assignment identity。
  • Advisor 可記錄是否顯示、是否互動、停留時間與「有幫助／還是不懂」回饋。
  • 後續 Run 可分類為：已修正、轉為其他錯誤、同錯誤持續、尚待下一次 Run。
  • 正式繳交可包含 advisor_summary.json 與 advisor_usage_summary，供教師診斷與後續研究分析。

作業資源政策

  • 程式／資料檔：單檔 2 MB。
  • 圖片：單檔 2 MB；音訊：單檔 5 MB；影片：單檔 10 MB。
  • 可匯出的作業內容總計 15 MB。
  • 匯入素材時立即檢查，也會偵測直接由 Windows 檔案總管複製進 Project 的檔案。
  • Mango App Exporter 系統輸出不納入作業繳交與容量計算。

教學與硬體整合

  • HostPython 教學範例 01–20 與多媒體／AI assets。
  • Standard Teaching Packages v1。
  • canonical mangobox import 與 legacy mangox2 相容。
  • 支援 MangoX2 + Pico／Pico W／Pico 2 W，以及 MangoLite + Pico W／Pico 2 W。
  • Mango App Exporter 可將桌面 Python 專案封裝成 Windows 執行程式。
