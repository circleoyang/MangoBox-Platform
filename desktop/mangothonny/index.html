MangoThonny

v0.4.1 StableWindowsPortable + Installer

MangoThonny 是 MangoBox 的教學用 Python 與實體運算 IDE。它以 Thonny Portable 為基礎，整合 MangoBox Host Student API、Mango App Exporter、教學套件、範例與 MangoBox 品牌介面，讓學生可以在同一環境中進行桌面 Python、MicroPython 與 Pico 實機操作。v0.4.1 為 Windows application identity 維護版，修正工作列釘選後可能顯示 Python 圖示與重新啟動 grouping 不一致的問題。

教學整合

  • HostPython 教學範例 01–20 與多媒體 / AI assets。
  • Standard Teaching Packages v1。
  • canonical mangobox import 與 legacy mangox2 相容。
  • Mango App Exporter 可將桌面 Python 專案打包為 Windows 執行程式。

硬體目標

  • MangoX2 + Pico
  • MangoX2 + Pico W
  • MangoX2 + Pico 2 W
  • MangoLite + Pico W
  • MangoLite + Pico 2 W

Windows 工作列修正

v0.4.1 對齊 MangoThonny 的 process、Workbench window 與 Installer shortcut identity。釘選、關閉與從 pinned icon 重新啟動皆已完成 exact-artifact smoke 驗證。
