MANGOTHONNY v0.4.0

安裝與使用說明

一般教學電腦建議使用 Installer；需要免安裝或隨身環境時使用 Portable ZIP。

1. Windows Installer

下載並執行 MangoThonny-Setup-v0.4.0.exe。安裝介面提供繁體中文。若希望建立桌面捷徑，請在安裝選項中勾選。

下載 Installer

Installer SHA-256：

01d4e994961220259c2ab593df6a043dc5a58a61e10868a746eac4820bc87c80

2. Portable

下載 MangoThonny-Portable-v0.4.0.zip 後解壓縮到可寫入的資料夾，再執行 MangoThonny.exe。若原生 launcher 無法使用，可改執行 MangoThonny.bat。

下載 Portable

Portable SHA-256：

24936c64a4b6b87ffe2969e4f7570227da4bfe89d313ab44ba44f05e4002ae16

3. Interpreter 切換

  • Host / CPython：使用 MangoThonny 內建 Python 執行桌面程式與 Host Student API。
  • Raspberry Pi Pico / MicroPython：連接 Pico 系列裝置後，可切換到 MicroPython interpreter 執行板端程式。
  • 正式版已驗證 Host → Pico → Host 來回切換。

4. MangoBox Host Student API

Host Python 建議使用 canonical import：

from mangobox import Mango

m = Mango()

舊教材的 import mangox2 仍保留相容性。Pico W target 會依 Runtime identity 正確辨識，不需要使用另一套 Student API。

5. 支援硬體

  • MangoX2 + Raspberry Pi Pico
  • MangoX2 + Raspberry Pi Pico W
  • MangoX2 + Raspberry Pi Pico 2 W
  • MangoLite + Raspberry Pi Pico W
  • MangoLite + Raspberry Pi Pico 2 W

6. 安裝版資料位置

Installer 模式將可寫資料與應用程式本體分離：

%LOCALAPPDATA%\MangoBox\MangoThonny\user_data
%LOCALAPPDATA%\MangoBox\MangoThonny\workspace
%LOCALAPPDATA%\MangoBox\MangoThonny\cache

因此執行範例、Exporter、Python bytecode 與 mypy cache 不會污染安裝目錄。解除安裝時可依提示選擇是否保留使用者設定與學習資料。

7. Mango App Exporter

MangoThonny 已內建 Mango App Exporter，可將桌面 Python 專案封裝為可攜式 Windows 執行程式。建議先確認程式在 MangoThonny 的 Host / CPython 模式可以正常執行，再進行 Export。
