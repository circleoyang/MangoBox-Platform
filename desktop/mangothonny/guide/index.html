MANGOTHONNY v0.4.3

安裝與使用說明

一般教學電腦建議使用 Installer；需要免安裝、隨身或測試環境時使用 Portable ZIP。v0.4.3 的重點是 Persistent Assignment 與完整 Learning Lifecycle：同一份作業可以跨多次執行、跨日期、跨 MangoThonny 啟閉，並可在不同電腦間延續。

前往下載中心

1. Windows Installer

公開發布後下載並執行 MangoThonny-Setup-v0.4.3.exe。安裝介面提供繁體中文。v0.4.3 已驗證 install、launch、shortcut、upgrade、uninstall 保留使用者資料，以及 reinstall 流程。

解除安裝時若要保留既有作業與學習資料，請選擇保留 MangoThonny 使用者資料。

2. Portable

下載 MangoThonny-Portable-v0.4.3.zip 後，解壓縮到可寫入的資料夾，再執行 MangoThonny.exe。若原生 launcher 無法使用，可改執行 MangoThonny.bat。

3. Interpreter 切換

  • Host / CPython：使用 MangoThonny 內建 Python 執行桌面程式與 Host Student API。
  • Raspberry Pi Pico / MicroPython：連接 Pico 系列裝置後，可切換到 MicroPython interpreter 執行板端程式。
  • v0.4.3 會明確區分 Host 與 RP2040、RPiPico、GenericMicroPython、MicroPython、CircuitPython 等 backend，避免 Learning Lifecycle 被錯誤分類。

4. MangoBox Host Student API

Host Python 建議使用 canonical import：

from mangobox import Mango

m = Mango()

舊教材的 import mangox2 仍保留相容性。MangoX2 與 MangoLite 的五個既有 target 功能維持原本 Student API 相容。

5. 建立學習作業

開啟 工具 → MangoBox 學習作業，輸入學號、作業代碼與作業資料夾後建立作業。系統會建立持久化 assignment_id，後續多次 Run、隔日繼續、重新啟動 MangoThonny 都會歸到同一份作業。

每次執行可記錄 run_start、code snapshot、程式輸出、runtime error、Student API / hardware evidence 與 run_end。

6. 帶走作業與跨電腦續作

  • 帶走作業：建立可續作 ZIP，包含程式、Assignment metadata、compact learning history 與 snapshots。
  • 匯入作業：在另一台電腦選擇 transfer ZIP，系統會建立新的本機 workspace、重設本機路徑，但保留原本 assignment_id。
  • 不同電腦使用匿名 computer_instance_id 區分，但不會把同一份作業拆成兩個 assignment。
  • 完成並匯出作業：作為最終繳交與研究分析用的 compact learning-history package。

7. Learning Log 與高頻感測資料

一般 Learning Log 仍可使用「本次執行、本次工作階段、今天、自訂時間範圍」匯出。Assignment 模式則額外維護跨 Run 的作業歷程。

Light、Sound、Joystick、PIR、IR、Ultrasonic、Obstacle 等連續讀取不會把每筆 polling 都塞進學生作業歷程；系統會以 bounded queue 與 constant-memory aggregation 產生 hardware_summary，保留 count、min、max、mean、latest 等統計。按下／放開、門檻跨越等真正有學習意義的事件仍會個別保存。

8. 安裝版資料位置

Installer 模式將可寫資料與應用程式本體分離：

%LOCALAPPDATA%\MangoBox\MangoThonny\user_data
%LOCALAPPDATA%\MangoBox\MangoThonny\workspace
%LOCALAPPDATA%\MangoBox\MangoThonny\cache

因此執行範例、Exporter、Learning Log、Python bytecode 與 cache 不會污染安裝目錄；解除安裝時可依提示選擇是否保留使用者設定與學習資料。

9. Mango App Exporter

MangoThonny 已內建 Mango App Exporter，可將桌面 Python 專案封裝為可攜式 Windows 執行程式。建議先確認程式在 Host / CPython 模式可以正常執行，再進行 Export。

v0.4.3 驗證摘要

已完成 Host Python 與 High-Level MicroPython lifecycle、runtime error、shared run_id、Light 高頻摘要、Ultrasonic distance() / is_near()、跨 process summary finalization、跨電腦 transfer/import/continue/re-export，以及 Installer install/launch/shortcut/upgrade/uninstall/reinstall smoke。
