Hardware Lab 安裝與使用說明

v0.2.0-rc5Windows 64-bit PortableFirmware / Lifecycle

Hardware Lab 是 MangoBox 的韌體與裝置生命週期工具，用於辨識目標板、更新 Firmware、Clean Flash、Factory Reset 輔助流程、維護手勢、執行模式切換、Recovery／Deep Rescue 與診斷報告。日常 GPIO／Pin 設定與感測器監看請使用 Device Manager。

下載 v0.2.0-rc5版本說明Device Manager 使用說明
本頁內容安裝選擇目標板連線資訊韌體更新Clean Flash維護手勢模式切換診斷報告常見問題

1. 下載與啟動

1
下載官方 Windows ZIP

取得 MangoBox-Hardware-Lab-v0.2.0-rc5-windows.zip。

2
完整解壓縮

將 ZIP 解壓到一般資料夾。不要直接從壓縮檔內執行 EXE。

3
啟動 Hardware Lab

在解壓後的資料夾內執行 Hardware Lab EXE。這是 Portable 套件，不需要安裝 Python。

若 Windows SmartScreen 出現提示，請先確認檔案來自本站 GitHub Release，再依 Windows 提示執行。
官方 Release SHA-256：2817b5678b43157fac7c7fdfa2fe092bf70d1df0c857ad7f86a5d75434ca9ca1

2. 先選對 Target

Hardware Lab 的第一個重要步驟不是燒錄，而是先選對硬體組合。不同 Target 的 MCU、UF2、Host UART、Gateway 能力與 Recovery 手勢都不同。

TargetMCUHost UART可用執行模式Recovery Button
MangoLite / Pico 2 WRP2350GP4 / GP5 · 115200Host UART / Gateway / MicroPythonGP3，固定板載
MangoX2 / PicoRP2040GP12 / GP13 · 115200Host UART / MicroPythonGP7，標準預裝但可拆除
MangoX2 / Pico 2 WRP2350GP12 / GP13 · 115200Host UART / Gateway / MicroPythonGP7，標準預裝但可拆除
MangoX2 / Pico 沒有 Gateway 模式。不要把 Pico 2 W 的操作流程或 UF2 套到普通 Pico。

3. 上方連線區怎麼填

選好 Target 後，按「重新整理」讓程式掃描可用連接埠。Hardware Lab 會顯示：

  • MicroUSB COM：Pico 原生 USB／管理通道。
  • USB-TTL / UART COM：Host UART 管理路徑。
  • Gateway URL：無線 Target 可使用，預設格式為 ws://mangobox-gateway.local:8765。
  • Device ID：需要指定 Gateway 裝置時填入，例如 MB001；切換不同 Target 時不應沿用舊板子的 Device ID。
不需要每次把三種路徑全部接上。Firmware、模式切換與 Recovery 會依 Target 與目前裝置狀態使用可行的管理路徑。

4. 一般韌體更新

  1. 在「韌體」頁按「選擇檔案」。
  2. 選擇與目前 Target 完全相符的 UF2。
  3. 確認 Target、MCU 與檔名，不要跨板型燒錄。
  4. 使用一般「更新韌體 / Update Flash」流程。
  5. 依畫面指示進入 UF2 模式；Hardware Lab 會辨識 RP2040 / RP2350 對應的磁碟。
  6. 等待複製、重新啟動與後續狀態檢查完成。
一般 Firmware Update 與 Clean Flash 的目的不同。單純更新 Runtime 時優先使用一般更新，不要把 Clean Flash 當成每次更新都要做的步驟。
燒錄前再次確認 Firmware 屬於目前選取的 Target。Hardware Lab 有 target-aware 防呆，但使用者仍應核對板型與版本。

5. Clean Flash 什麼時候用？

Clean Flash 是較深層的重新部署流程，適合裝置設定、執行模式或檔案系統已經混亂，單純更新 Firmware 無法恢復正常狀態時使用。它會結合 Factory Reset-assisted deployment、重新進入 UF2、重新燒錄與目標執行模式設定。

Clean Flash 可能改變或清除裝置設定。若目前設定仍可由 Device Manager 匯出，建議先備份。學生程式是否保留、protected config 如何處理，依當前 Runtime 的 Factory Reset / deployment contract 為準，請以 Hardware Lab 畫面與診斷結果為準。
  1. 確認 Target 正確。
  2. 選擇正確 UF2。
  3. 在「初始模式」選擇 Clean Flash 完成後希望進入的模式；一般維護可優先選 MicroPython。
  4. 按「Clean Flash」。
  5. 依畫面指示完成 Factory Reset、重新連線、Bootloader / UF2 與後續驗證。
  6. 不要在流程中任意拔線或關閉程式，除非畫面明確要求。

6. Button + RESET 維護手勢

「維護手勢」頁可協助驗證 Normal、Recovery、Deep Rescue 與 Cancel。先依畫面選擇手勢與目前 stored mode，再使用計時器配合實機操作。

手勢按住 Recovery Button 的時間用途
Normal< 2 秒一般開機，不進入維護模式。
Recovery2–<10 秒進入 Recovery 路徑。
Deep Rescue10–<20 秒進入更深層維護／救援路徑。
Cancel≥20 秒取消維護手勢並回到 Normal。

實際按法

  1. 先按住 Recovery Button。
  2. 短按 RESET，RESET 放開後 Recovery Button 繼續按住。
  3. 依目標時間與板上聲光提示判斷。
  4. 到達要測試的區間後放開 Recovery Button。
MangoLite：GP3 是固定板載按鈕，可依板載 RGB 與蜂鳴器提示操作。
MangoX2：GP7 是標準預裝但可拆除的 Button；若已拆除，手勢測試為 N/A，不代表硬體故障。MangoX2 固定板載蜂鳴器是較可靠的提示來源，RGB 若仍安裝可作為輔助。

7. 偵測與切換執行模式

在「執行模式」頁可先 Probe Current Mode，再選擇目標模式並切換。Preferred Path 建議先使用 Auto，讓 Hardware Lab 依目前 Target 與可用傳輸選擇管理路徑。

模式用途常見情境
MicroPython直接在 Pico 上執行高層／低層 MicroPython。Thonny、Creator Device-side 程式。
Host UART由上位機 Python 透過 Host UART 控制 Runtime。MangoThonny / PC Python。
Gateway透過 Wi‑Fi Gateway 集中管理。MangoLite / Pico 2 W 或 MangoX2 / Pico 2 W 教室部署。
模式切換會讓裝置 reboot／重新連線。切換後請等 Hardware Lab 完成 post-reboot verification，再開始下一個動作。

8. 診斷紀錄與報告

視窗下方會累積結構化診斷事件。遇到問題時，不要只截一張「失敗」畫面，建議保留完整紀錄：

  • 複製紀錄：快速貼到 GitHub Issue、ChatGPT 或團隊討論。
  • 儲存報告：輸出 JSON，包含 app version、Target、選擇的 COM Port、Gateway、Firmware 與診斷事件。
  • 清除紀錄：開始下一輪獨立測試前再清除。
若需要協助排查，建議一起提供：Target、目前 Runtime version、執行模式、實際接線、Hardware Lab JSON report，以及你剛才執行的動作。

9. 常見問題與工具分工

選了 UF2，但 Hardware Lab 不接受

先確認 Target 是否選錯，尤其 MangoX2 / Pico 與 MangoX2 / Pico 2 W 是不同 MCU、不同 UF2。

找不到 MicroUSB

  • 確認 USB 線可傳資料。
  • 按「重新整理」。
  • 若裝置正在被 Thonny 使用，先釋放 COM Port。
  • 若需要 ROM UF2，依畫面提示進入 Bootloader。

找不到 Host UART

  • 確認 USB-to-TTL 驅動與 COM Port。
  • MangoLite Host UART 為 GP4 / GP5；MangoX2 為 GP12 / GP13，115200。
  • TX / RX 要交叉接，並共地。

只是想改 Servo / PIR / Light 的 Pin，要用這裡嗎？

不用。這類日常模組與 Pin 設定請使用 Device Manager。Hardware Lab 不把一般 GPIO／ADC／RGB／OLED／Servo／Sensor production test 宣稱為目前公開功能。

你要做的事請使用
改 GPIO／Pin、Enable module、校準、即時讀值Device Manager
Firmware Update、Clean Flash、Factory ResetHardware Lab
Recovery／Deep Rescue、模式卡住、無法回 RuntimeHardware Lab
正常寫程式、積木、執行學生作品MangoBox Creator / Thonny
