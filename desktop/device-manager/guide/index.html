Device Manager 安裝與使用說明

v0.5.0-rc8Windows 64-bitInstaller + PortableMangoX2 / MangoLite

Device Manager 用於 MangoBox 的日常裝置管理：連線裝置、查看 Runtime 狀態、設定模組與 GPIO／Pin、備份與還原設定、校準，以及支援範圍內的即時讀值與監看。韌體燒錄、Clean Flash、Factory Reset、Recovery／Deep Rescue 請改用 Hardware Lab。

1. 下載與安裝

一般使用者：Installer

1
下載安裝版

取得 MangoBox_Device_Manager_v0.5.0-rc8_Setup.exe。

2
執行繁體中文安裝精靈

依畫面完成安裝。程式會建立開始選單捷徑，並可選擇建立桌面捷徑。

3
啟動程式

從開始選單或桌面捷徑開啟 MangoBox Device Manager。

rc8 Installer 已完成 Windows 安裝、啟動、捷徑與繁體中文解除安裝流程驗證。

免安裝：Portable

  1. 下載 MangoBox_Device_Manager_v0.5.0-rc8_Portable.zip。
  2. 完整解壓縮到一般資料夾，不要直接在 ZIP 裡執行。
  3. 執行 MangoBox_Device_Manager_v0.5.0-rc8.exe。
Installer 與 Portable 來自同一份已驗證 binary tree；兩個 Release asset 都會附 SHA-256 檢查檔。
若 Windows SmartScreen 第一次執行時出現保護提示，請先確認檔案確實來自 MangoBox 官方 GitHub Release，再依 Windows 提示決定是否執行。

2. 第一次連線

  1. 以 USB 將 MangoX2 或 MangoLite 連接到電腦。
  2. 開啟 Device Manager，在上方選擇適合的「連線方式」。
  3. 按「重新整理」，確認清單中出現正確的 COM Port。
  4. 選擇 COM Port 後按「連線」。
  5. 連線成功後，先確認裝置名稱、Runtime Version、Target 與連線狀態，再進行設定。
同一個 MicroUSB COM Port 同一時間只能由一個程式控制。若 Thonny／MangoThonny 正在連線 Pico，請先停止程式並釋放該 COM Port，再讓 Device Manager 連線。
rc8 可辨識 MangoX2 + Pico、MangoX2 + Pico 2 W、MangoX2 + Pico W、MangoLite + Pico 2 W、MangoLite + Pico W。實際可用模組仍依 Runtime 與目前 config 為準。

3. 兩種常用連線方式

連線方式適合情境接線注意事項
MicroUSB / Pico高層 MicroPython 教學、裝置設定、支援範圍內的感測器讀值／監看、完整 OLED 持久字庫管理。Pico 原生 MicroUSB／USB 資料線。使用前先讓 Thonny／MangoThonny 釋放 Pico COM Port。
Runtime UART透過正在執行的 Mango Runtime 做管理與即時控制。USB-to-TTL 接到該板的 Host UART，並共地。程式會等待 Runtime readiness 回應；COM 開啟不代表 Runtime 已準備完成。

rc8 在 MangoX2 從 MicroUSB / Pico 回到 Runtime UART 時，會等待正常 reboot 後再進行單次 readiness/config refresh，避免同一輪恢復重複讀取多次裝置資訊。

4. 模組與 GPIO／Pin 設定

建議操作順序

  1. 先連線裝置，進入「腳位設定」。
  2. 按「從裝置讀取設定」，以 Runtime 目前真正的設定為基準。
  3. 從裝置清單選擇要修改的模組，或使用「新增裝置」。
  4. 設定 Enable、GPIO／Pin、Pull、Active、Debounce 或該模組需要的參數。
  5. 確認畫面沒有 GPIO 衝突或固定腳位限制。
  6. 按「儲存變更」，再重新讀取確認。
  7. 若畫面提示需要重新啟動，請依提示 Reboot。
ADC 腳位顯示會對齊板上絲印：GP26 (AD0)、GP27 (AD1)、GP28 (AD2)。括號是 UI 顯示名稱，Runtime config 的 GPIO 數值仍是 26、27、28。
固定硬體不應任意改腳位。不要把另一種板型的設定檔直接套用到目前裝置；匯入前請確認 Board / Target。

5. 即時測試與監看

連線與設定完成後，可依目前 Target／Runtime 支援情況使用控制與監看頁面，例如 RGB、OLED、蜂鳴器、Button、Servo，以及目前已實作 Live Read / Monitor／校準流程的感測器。

  • 先確認模組是否 Enabled。
  • 確認畫面中的 Pin 與真機 Signal 接線一致。
  • 先用 Read Once / Monitor 做最小測試，再回到完整學生程式。
  • 不同 Runtime 版本與模組的 Live Read / Monitor 支援程度不同，以目前頁面與 Runtime 回覆為準。
Device Manager 優先走既有 MangoBox Student API / Runtime 路徑，不應在設定錯誤時偷偷繞過目前 config 直接讀 GPIO。

6. 備份、匯入與還原

  • 匯出／備份：保存目前設定。
  • 匯入：把選擇的設定項目套回裝置；先確認 Board / Target 相符。
  • Restore / Defaults：屬較大的設定變更，使用前先確認影響範圍。

變更後建議重新讀取 config，確認 Runtime 接受的結果與畫面一致。

7. OLED 中文字型

OLED 字型頁可協助分析程式／教材中缺少的中文字並寫入字模。rc8 對兩種連線方式的 UI 分工如下：

模式字模分析／寫入目前學生自訂字庫管理

8. 常見問題

找不到 COM Port

  1. 確認 USB 資料線與轉接器已接好。
  2. 按「重新整理」。
  3. 若使用 MicroUSB / Pico，先確認 Thonny／MangoThonny 已釋放該 COM Port。

連上了但讀不到設定

  1. 先確認 Target / Runtime version 是否正確。
  2. Runtime UART 請等待 readiness，不要只看 Port 是否成功開啟。
  3. 若問題涉及 firmware、execution_mode、Recovery、Clean Flash 或刷錯 MCU，請改用 Hardware Lab。

Sensor 沒反應

  1. 確認 Enable。
  2. 確認 Pin / 真機接線。
  3. 用 Device Manager 的最小 Live Read / Monitor（若支援）確認。
  4. 再進一步檢查 raw input、供電與 calibration。
若問題是韌體版本、Target / MCU、Recovery / Rescue、Factory Reset 或 Clean Flash，請直接改用 Hardware Lab，不要在 Device Manager 裡反覆嘗試。
