Device Manager 安裝與使用說明

v0.5.0 StableWindows 64-bitInstaller + PortableMangoX2 / MangoLite

Device Manager 用於 MangoBox 的日常裝置管理：辨識與連線裝置、查看 Runtime 狀態、設定模組與 GPIO／Pin、同步設定、校準，以及支援範圍內的即時讀值與監看。韌體燒錄、Clean Flash、Factory Reset、Recovery／Deep Rescue 請改用 Hardware Lab。

本頁內容安裝支援 Target連線腳位與設定即時測試語言常見問題

1. 下載與安裝

一般使用者：Installer

  1. 下載 MangoBox_Device_Manager_v0.5.0_Setup.exe。
  2. 執行繁體中文安裝精靈，依需求建立開始選單與桌面捷徑。
  3. 安裝完成後啟動 MangoBox Device Manager，確認標題與 About 顯示 v0.5.0。
v0.5.0 Installer 已完成安裝、啟動、Start Menu、Desktop shortcut、ICON、About、zh → en → zh 切換與解除安裝 smoke。

免安裝：Portable

  1. 下載 MangoBox_Device_Manager_v0.5.0_Portable.zip。
  2. 完整解壓縮到一般資料夾，不要直接在 ZIP 內執行。
  3. 執行解壓後的 Device Manager EXE。

3. 連線方式

Runtime UART

適合透過正在執行的 Mango Runtime 進行日常管理與即時控制。請選擇正確 COM Port 後連線，待 Runtime readiness 與 config 載入完成再操作。

MicroUSB / Pico

適合直接透過 Pico 原生 USB 進行設定與支援範圍內的即時讀取。若 Thonny／MangoThonny 正在使用同一個 COM Port，請先停止程式並釋放連線。

切換裝置或 Target 後，先確認畫面上的 Board、Target 與目前 config 已更新，不要把上一塊板的設定直接套到新裝置。

4. 模組、GPIO／Pin 與設定

  1. 連線後先從裝置讀取目前設定。
  2. 選擇模組，確認 Enable 狀態與 GPIO／Pin。
  3. 修改必要參數後儲存。
  4. 重新讀取設定，確認裝置端與 UI 同步。
  5. 若系統提示需重新啟動，依提示 Reboot 後再確認。
ADC 顯示會對齊板上絲印：GP26 (AD0)、GP27 (AD1)、GP28 (AD2)；Runtime config 儲存的 GPIO 數值仍為 26、27、28。

5. 即時測試與監看

依目前 Runtime capability 與模組 Enable 狀態，Device Manager 會顯示可用的即時控制、Read Once、Monitor 或校準頁面。建議先用最小測試確認硬體，再回到學生程式。

  • RGB / OLED / Buzzer / Button 等功能依板型與 config 顯示。
  • 感測器頁面只在目前裝置與設定支援時顯示。
  • Motor / Drive 操作後務必停止輸出，再切換頁面或裝置。
Stable promotion 另外完成 MangoX2 + Pico W 的 Runtime UART / MicroUSB / RGB smoke，以及 MangoLite + Pico W 的 Runtime UART / RGB / onboard IR / config smoke。

6. 繁體中文 / English

可直接在程式內切換繁體中文與 English。v0.5.0 採即時 retranslate，不重建目前頁面；目前頁面、導覽與裝置狀態會維持。

7. 常見問題

找不到 COM Port

  • 確認 USB 線具備資料傳輸能力。
  • 關閉可能占用 COM Port 的 Thonny／MangoThonny 或其他 Serial 工具。
  • 按重新整理後再選擇 COM Port。

連線成功但設定沒有更新

  • 確認 Board / Target 是否與目前硬體一致。
  • 重新讀取 system/info 與 config。
  • 若剛從 MicroUSB 切回 Runtime UART，等裝置 reboot 與 Runtime readiness 完成後再操作。

需要重灌韌體或 Recovery

請使用 Hardware Lab，不要在 Device Manager 進行韌體生命週期維護。
