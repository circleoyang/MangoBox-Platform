MANGOBOX DEVICE MANAGER

裝置管理器

MangoBox 裝置管理器是日常設定與裝置管理工具，用來連線 MangoX2／MangoLite、管理模組啟用狀態、GPIO／Pin 設定、校準，以及即時讀值與監看。需要韌體更新、Clean Flash、Factory Reset 或 Recovery 時，則交由硬體實驗室處理。

主要功能

裝置連線

辨識並連線 MangoBox 裝置，提供日常使用所需的裝置資訊與連線狀態。

模組與腳位設定

管理模組 Enable、GPIO／Pin 對應與必要設定，讓硬體配置與程式使用方式保持一致。

校準與即時監看

支援裝置校準、即時讀值與 Monitor，協助教師與學生確認感測器及模組狀態。
