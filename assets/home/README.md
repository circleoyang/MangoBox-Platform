# MangoBox Homepage Images

This folder contains homepage artwork and product imagery for MangoBox.

## Current image assets

- `mangobox-hero.png` — homepage classroom hero artwork.
- `raspberry-pi-pico.png` — Raspberry Pi Pico core computing unit.
- `raspberry-pi-pico-w.png` — Raspberry Pi Pico W core computing unit.
- `raspberry-pi-pico-2-w.png` — Raspberry Pi Pico 2 W core computing unit.
- `mangox2-board.webp` — optimized transparent MangoX2 physical-computing board product image.
- `mangolite-board.webp` — optimized transparent MangoLite physical-computing board product image.

The board images are displayed in the homepage **Physical Computing Boards / 實體運算電路板** section below each board's descriptive copy.
