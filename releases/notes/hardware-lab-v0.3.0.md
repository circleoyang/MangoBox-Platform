# MangoBox Hardware Lab v0.3.0

## 中文

Hardware Lab v0.3.0 正式版，提供 Windows 64-bit Installer 與 Portable。支援 MangoX2 + Pico／Pico W／Pico 2 W，以及 MangoLite + Pico W／Pico 2 W。提供雙語介面、韌體維護與單次 UF2 教師套件部署。Teacher Profile v1 為預設；v2 仍為需明確啟用的實驗功能。

安裝 Installer，或完整解壓 Portable 後執行 MangoBox Hardware Lab.exe；不需另外安裝 Python。

本機 Windows 建置；使用者回報正式版 smoke PASS，先前代表機驗收通過。五個 UF2 已核對正式版內嵌版本與 MCU family，未宣稱五台新機各自重做完整實機驗證。

## English

Stable Hardware Lab v0.3.0 for Windows 64-bit, with Installer and Portable distributions. Supports all five MangoX2/MangoLite targets, bilingual UI and one-UF2 Teacher Profile deployment. Profile v1 is the default; Profile v2 remains opt-in experimental. Install Setup or extract the entire Portable ZIP and launch MangoBox Hardware Lab.exe. Python is not required.

Built locally on Windows. The user reported final smoke PASS following representative hardware acceptance. All five UF2 embedded release versions and MCU families were checked. This does not claim a new full physical test on every target.
