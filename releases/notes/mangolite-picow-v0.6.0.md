# MangoLite Runtime v0.6.0 — Pico W

## 中文

MangoLite Runtime v0.6.0 正式版，僅適用 MangoLite + Raspberry Pi Pico W。搭配 Hardware Lab v0.3.0 使用，保留既有 Student API、執行模式與維護路徑。

在 Hardware Lab 選擇正確主板與控制板，再選本 Release 的 UF2，依指示燒錄。更新前請備份需要保留的學生程式與設定。

本機 Windows 建置；使用者回報正式版 smoke PASS，先前代表機驗收通過。五個 UF2 已核對正式版內嵌版本與 MCU family，未宣稱五台新機各自重做完整實機驗證。

## English

Stable MangoLite Runtime v0.6.0 for MangoLite + Raspberry Pi Pico W only. Use Hardware Lab v0.3.0, select the matching carrier/controller and UF2, then follow the flashing instructions. Back up student files and settings before updating.

Built locally on Windows. The user reported final smoke PASS following representative hardware acceptance. All five UF2 embedded release versions and MCU families were checked. This does not claim a new full physical test on every target.
